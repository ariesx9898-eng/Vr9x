# Fittoa terrain source (generated)

Generated by `python3 Tools/generate_fittoa_terrain.py --seed 1717` (about 18 s, numpy + Pillow). Every file here is
reproducible from that command; do not hand-edit them. Re-run the script instead.

| File | What it is |
|---|---|
| `Fittoa_Height_2017.png` | 16-bit greyscale heightmap, 2017 x 2017 |
| `Fittoa_Height_2017.r16` | The same heights as raw little-endian uint16 |
| `Fittoa_W_{grass,farmland,forest_floor,dirt_road,riverbed,rock}.png` | 8-bit weight maps. They add up to exactly 255 on every pixel |
| `Fittoa_Preview.png` | Colour preview: the weights multiplied by a hillshade |
| `fittoa_layout.json` | Landscape settings, height range and key locations in UE cm |

## Landscape import (Landscape mode > New > Import from File)

| Setting | Value |
|---|---|
| Location | **(0, 0, 0)**. UE centres a new landscape on this point, so the actor ends up at (-100800, -100800, 0). |
| Rotation | (0, 0, 0) |
| Scale | **X = 100, Y = 100, Z = 100**. That is 1 m per sample, 2016 m x 2016 m in total. |
| Section size / sections per component / components | 63x63 quads / 2x2 / 16x16 (overall resolution 2017) |
| World Partition landscape grid size | 2 components (252 m streaming proxies) |
| Layers | Weight-blended layers `grass, farmland, forest_floor, dirt_road, riverbed, rock`. Assign each PNG to the layer with the same name. |

Height encoding: Z scale 100 gives 1 unit = 100/128 = 0.78125 cm, and value 32768 = Z 0 cm. The terrain goes from
25.2 m to 235.6 m, so the values stay between 35998 and 62928 and nothing is clipped.

World position of a pixel: `X = (col - 1008) * 100`, `Y = (row - 1008) * 100`, `Z = height_cm`.
Image up (row 0) is **north = -Y**, and image right is **east = +X**.
